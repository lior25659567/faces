# Mixamo motions — what to download

## Steps
1. Go to **mixamo.com** and sign in with your Adobe account (free).
2. Click **Animations** at the top. Leave the default character (Y Bot) — we only need the motion.
3. Search for an exercise (list below). Click one to preview it on the character.
4. Click **Download** and use exactly these settings:
   - **Format:** FBX Binary (.fbx)
   - **Skin:** Without Skin   ← we only need the motion, not their character
   - **Frames per Second:** 30
   - **Keyframe Reduction:** none
5. Rename the file to the exercise name below and drop it **in this folder**.

If an exercise has several versions, download the 2–3 that look closest to good form —
I'll compare them against the sourced form angles and pick the best one.
If you can't find an exercise, skip it and tell me. I'll animate those by hand.
