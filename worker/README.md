# faces-avatar worker

Draws the avatar, so the phone never holds a Cloudflare token.

The iOS app can call Workers AI directly, and while it runs on one developer's device from Xcode
that is fine. It is not fine in a build anybody can download: a token on a device is a token its
owner can extract, and every call it makes is spent against the account that issued it. This
Worker exists so the credential stays on Cloudflare's side. It reaches Workers AI through the
`AI` binding, so there is no token anywhere in the request path — not in the app, not in this
source, not in an environment variable.

## Deploy

```
cd worker
npx wrangler login     # once
npx wrangler deploy
```

Wrangler prints the address it deployed to, something like
`https://faces-avatar.<your-subdomain>.workers.dev`.

## Point the app at it

In the app, the backend changes from the local-development one to the Worker:

```swift
AvatarService(backend: .worker(url: URL(string: "https://faces-avatar.…workers.dev")!))
```

After that the keychain credential is no longer used for anything, and `SettingsView`'s
Cloudflare section can go. Until then the app keeps working exactly as it does now — the two
backends speak the same protocol, which is why this swap is one line.

## What it does

The same two steps as `pipeline/restyle.py`: ask a vision model to describe the person, build the
drawing prompt from that description, then ask the image model to redraw the photo as the avatar.

`src/prompt.js` is a port of the Python's prompt construction and has to stay exact. A person's
seed comes from their character name so that their repeat progress photos draw the SAME
character, and that only holds while the prompt is identical too — a reworded clause makes the
phone draw a different person from the one the Mac drew, and the before-and-after comparison is
then comparing two strangers.

```
npm test
```

checks it against `faces-ios/Tests/Fixtures/prompt-golden.json`, which was generated by running
the Python itself (`pipeline/prompt_golden.py`). 32 assertions, including every skin shade, every
body word in order, and the full prompt for each golden case.
